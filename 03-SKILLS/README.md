# Skills System

First Root maintains a small set of living Skills.  
These start simple and grow **only** through verified 9-phases (Complete / Return to Essence).

## The Five Core Skills

| Skill                  | Purpose                                      |
|------------------------|----------------------------------------------|
| `first-root-core`      | Identity, principles, voice, autonomy rules  |
| `business-context`     | Living profile of the specific business      |
| `knowledge-garden`     | Research, insights, processes, ops intelligence |
| `outreach-playbook`    | Sales outreach engine and pipeline           |
| `spiral-logs`          | Memory of cycles and regeneration            |

New information only enters a Skill after a verified **9 – Complete** phase.  
The Orchestrator decides which Skill to update.
