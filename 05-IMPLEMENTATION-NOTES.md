# Implementation Notes

## Dedicated Gmail
Create a separate Gmail account for First Root (e.g. firstroot@yourdomain.com or a free Gmail).  
Grant it access only when you are ready to raise autonomy beyond Level 0.

## Raising Autonomy
Only raise the autonomy level after you have seen consistent, high-quality drafts and verified results.  
Always define the exact scope when granting higher levels.

## Hermes / Local Path (Pro)
Once the cloud version is trusted, you can run a local Hermes instance with the same Skills for richer on-device memory and persistence. This is optional and recommended only after the basic system is working well.

## Evolution Rule
Complexity should only increase when the specific business context demands it.  
Resist the urge to add new specialists or tools prematurely.

## Success Metrics (Learning-Oriented)
- Pipeline generated
- Conversations started
- Revenue influenced
- Founder hours protected
- Clarity created
- Knowledge quality improvements
