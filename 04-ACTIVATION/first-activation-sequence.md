# First Activation Sequence

**Goal:** Bring First Root online in under 60–90 minutes and complete the first full 3-6-9 cycle.

## Phase 0: Setup (15–20 min)

1. Create the Core Skill `first-root-core` and paste the full system prompt into it.
2. Create the four supporting Skills (empty is fine):
   - `business-context`
   - `knowledge-garden`
   - `outreach-playbook`
   - `spiral-logs`
3. Explicitly set autonomy to Level 0: “Remain at Level 0 (always ask for approval) until I raise it.”

## Phase 1: Seed the Living Knowledge (3 – Diverge)

Open a new conversation and paste:

```
First Root, we are beginning your first activation.

Current cycle: 3 – Diverge.

Please ask me the minimum set of high-leverage questions needed to create a solid first version of the business-context Skill. 

Focus only on what is essential for you to start supporting knowledge, research/ops, and sales outreach effectively. Keep the questions clear and structured so I can answer quickly.
```

Answer the questions, then instruct:

```
Update the business-context Skill with everything you just learned. Confirm when the Skill has been updated.
```

## Phase 2: First Integration (6 – Integrate)

```
Move to 6 – Integrate.

Using only the information now in business-context, propose the highest-leverage next actions in these three areas:

1. Strengthening the living knowledge base
2. One useful research or ops insight I should have right now
3. The simplest possible first outreach experiment (draft only)

Present each recommendation clearly for my approval.
```

## Phase 3: First Completion (9 – Complete / Return)

```
Move to 9 – Complete / Return to Essence.

1. Summarize what we learned in this first cycle.
2. Update the spiral-logs Skill with a clean record of this cycle.
3. Update any other Skills if new durable knowledge was created.
4. Recommend the single best next action for our next cycle.
```

## Phase 4: Establish the Rhythm

```
From now on, at the start of every new major piece of work or at the beginning of each week, explicitly state which phase of the 3-6-9 cycle we are in and what the intended outcome is. 

We will run a short weekly regeneration (9-phase) every Friday or Sunday.
```
