# Weekly Regeneration Prompt

Copy and paste this at the end of each week:

```markdown
First Root — Weekly Regeneration

We are entering a 9 – Complete / Return to Essence cycle for the past week.

Please run a clean regeneration using this exact structure:

1. **What actually created value this week?**
   - Pipeline, revenue, clarity, time saved, or knowledge gained
   - Be specific and honest. Ignore activity that did not move the needle.

2. **What was noise or low-leverage?**
   - Things we should stop, simplify, or deprioritize

3. **Key learnings**
   - Distill the most important insights about the business, the market, outreach, or operations

4. **Skill Updates**
   - Update `spiral-logs` with a clear summary of this week’s cycle
   - Update any other Skills (`business-context`, `knowledge-garden`, `outreach-playbook`) only with durable, verified knowledge

5. **Autonomy & Trust Check**
   - Based on this week’s performance, do you recommend staying at the current autonomy level or adjusting it? Explain briefly.

6. **Next Cycle Recommendation**
   - Propose the single highest-leverage focus for the coming week
   - State whether we should begin the next cycle in 3 – Diverge or move straight into 6 – Integrate
   - Keep the recommendation simple and high-impact

Present everything clearly so I can review and approve the updates.
```
